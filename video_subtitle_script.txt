Edge TTS Studio 口播稿（约 1 分钟，约 300 字）
用途：GitHub 开源项目介绍视频配音
语速参考：正常播报约 60-70 秒

--------------------------------------------------

Edge TTS Studio，一款用 Rust 打造的 macOS 轻量文字转语音工具。它接入微软 Edge 的朗读服务，输入任意文字，一键合成，直接导出 MP3。

界面默认中文，一键切换英文，支持中英双语语音搜索，上百种音色随便挑。每种音色都能试听，语速、音量随时调节。长文档也不怕，专属编辑器独立滚动，大段文字照样轻松处理。

技术上，它是纯 Rust 实现：语音获取和合成都跑在后台线程，界面永不卡顿；语音列表自动缓存，网络波动也能正常选音色。从访达直接启动也没问题，它会自动读取系统代理，国内网络环境同样可用。

最关键的是——完全免费，无需任何 API Key。装好 Rust，一条命令即可编译运行。

无论是视频配音、有声书制作，还是学习资料朗读，它都能帮你省下大笔配音成本。
